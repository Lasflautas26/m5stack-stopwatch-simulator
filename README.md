If you see a warning from Windows SmartScreen, click "More info" and then "Run anyway." This is normal for downloaded applications and is just a safety check.

### The simulator doesn't start. What should I do?

Make sure you've extracted all files from the zip folder. Then try running the application as administrator by right-clicking and selecting "Run as administrator."

### Can I use this on a Mac?

This version is designed for Windows. However, the simulator is based on open-source code, so you might find Mac instructions in the project's documentation.

### Is this the real M5Stack device?

No, this is a simulator. It runs the actual firmware code but displays it on your computer screen instead of the physical hardware.
